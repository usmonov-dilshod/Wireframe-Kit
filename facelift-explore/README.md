# Facelift Explore

Статический сайт: каталог техник подтяжки лица + 3D-анимация deep-plane.

- `index.html`, `styles.css`, `app.js`
- `data/techniques.json`
- `animation.html`, `animation.js`
- `icons/`

Запуск локально (для загрузки JSON):

1. Запустите сервер: `python3 -m http.server 8080 --directory facelift-explore`
2. Откройте: `http://localhost:8080`
